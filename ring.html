How the AI brain works: Ring runs a small AI model directly inside your browser using WebGPU. Nothing is sent to any server — no API key, no sign-up, totally free, and it even keeps working without internet once the model is cached.
Device support: needs a browser with WebGPU — recent Chrome or Edge (desktop works best; newer Android Chrome too). Safari and older browsers can't run the on-device AI yet.
About voice input: Chrome, Edge, and most Android browsers can listen to you speak. Safari (iPhone/iPad/Mac) doesn't support browser speech recognition at all. Either way you can always type in the box below the call button — replies are always spoken out loud too.
Mic not working on phone? Voice input needs a secure page (opened via https://, e.g. hosted on GitHub Pages/Netlify). If you opened this file directly on your phone, the mic may be blocked — typing still works instantly either way.
